### 專案介紹
這個專案是ECommerce的後端儀表板。平台中，管理員可以透過KPI、表以及其他顯示資料的工具。可以簡單查詢店的經營表現，除了此之外，也可以透過平台管理店內的
所有商品、訂單以及員工。如果以管理員帳號登入平台，則會收到完正授權，授權包括：讀取、新增、更正以及刪除資料。
