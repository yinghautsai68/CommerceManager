# CommerceManager
## 全端儀錶板
### DEMO連結

### 專案介紹
專案是ECommerce的後端儀表板，平台中，透過KPI、表以及其他顯示資料的工具等等 可以簡單查詢店的表現。除了此之外，也=可以透管理店內的
所有商品、訂單以及員工。以管理員帳號登入平台的話，即會收到所有授權，可以讀取、新增、更正以及刪除資料。
